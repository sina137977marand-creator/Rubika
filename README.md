# ربات مدیریت گروه روبیکا (با توکن رسمی، پایتون)

## ⚠️ دکمه‌های شیشه‌ای عمداً استفاده نشدن
طبق مستندات رسمی روبیکا و تست واقعی، کلیک روی دکمه‌ی شیشه‌ای (Inline Keypad) فقط
از طریق **وب‌هوک** (سرور عمومی با HTTPS) قابل دریافته، نه از طریق polling ساده‌ای
که این ربات (مناسب تست روی گوشی/Pydroid، بدون سرور عمومی) استفاده می‌کنه. برای
همین همه‌چیز اینجا **کاملاً متنی** طراحی شده — با نوشتن کلمه یا شماره‌ی گزینه کار
می‌کنه، نه کلیک. این تضمین می‌کنه همیشه (حتی بدون سرور) کار کنه. وقتی روی یک VPS
با دامنه و HTTPS مستقر شدید، اگه خواستید می‌شه وب‌هوک راه انداخت و دکمه اضافه کرد.

## ⚠️ محدودیت‌های واقعی API رسمی روبیکا
API رسمی ربات‌های روبیکا (که این پروژه ازش استفاده می‌کنه) برخلاف تلگرام **متدهایی برای
کیک/بن واقعی، سکوت واقعی (محدودسازی ارسال پیام)، ارتقا به ادمین گروه، یا دیدن لیست
ادمین‌های واقعی گروه نداره.** به همین خاطر:

- **بن/سکوت در این ربات «نرم» هستن**: یعنی ربات به‌جای اخراج واقعی، فقط پیام‌های اون
  کاربر رو خودکار حذف می‌کنه. برای اخراج واقعی، یک ادمین واقعی باید دستی داخل اپ روبیکا
  این کارو انجام بده.
- **سیستم ادمین/مالک، مال خود رباته نه پلتفرم روبیکا**: هرکی تو گروه بگه «فعالسازی»،
  به‌عنوان «مالک گروه» در دیتابیس ربات ثبت میشه و می‌تونه با ریپلای و گفتن «افزودن ادمین»
  به بقیه هم دسترسی ادمین ربات بده. این ربطی به ادمین‌بودن واقعی در روبیکا نداره.
- **شناسایی کاربر ریپلای‌شده از طریق ایندکس داخلی رباته**: چون متد رسمی `get_message`
  برای این کار جواب نمی‌ده، ربات خودش هر پیام گروه رو (فرستنده + آیدی پیام) تو دیتابیس
  ثبت می‌کنه. یعنی برای این‌که «بن/سکوت/افزایش موجودی و ...» با ریپلای کار کنه، ربات
  باید موقع ارسال اون پیام روشن بوده باشه و پیام رو دیده باشه.
- **تشخیص گیف/عکس/فوروارد به‌صورت best-effort نوشته شده** چون ساختار دقیق پیام‌های
  روبیکا عمومی مستند نیست. اگه بعد از تست رو گروه واقعی درست کار نکرد، به فایل

  `utils.py` تابع `guess_message_kind` سر بزنید و بر اساس خروجی واقعی
  (که می‌تونید با `print(message.raw_data)` ببینید) اصلاحش کنید.
- **قابلیت باز/بسته کردن گروه با ساعت معین حذف شد** چون معادل
  `set_chat_permissions` تلگرام در API روبیکا وجود نداره.
- **خوش‌آمدگویی با یه روش جایگزین پیاده شده**: چون مطمئن نبودیم رویداد «عضو جدید
  اومد» واقعاً به بات می‌رسه یا نه، به‌جاش با اولین پیامی که هرکس تو گروه می‌فرسته
  (که ربات قبلاً ندیدتش) بهش خوش‌آمد گفته میشه. یعنی اگه عضوی وارد بشه ولی پیام نده،
  خوش‌آمد نمی‌گیره تا وقتی اولین پیامش رو بفرسته.
- **تگ کردن اعضا واقعی/کلیک‌خور نیست** (چون Mention واقعی در پیام متنی مستند نبود)؛
  دستور «تگ» اسم اعضایی که ربات ازشون پیام دیده رو تو یه پیام لیست می‌کنه.

اگه هرکدوم از این محدودیت‌ها براتون مهمه و حتماً لازمشون دارید، تنها راه واقعی همون
روش سلف‌بات (لاگین با شماره، rubpy/pyrubi) هست که قبلاً درباره‌ش صحبت کردیم.

## امکانات کامل
مدیریت: فعال‌سازی، تنظیمات دکمه‌ای (قفل لینک/فوروارد/گیف/عکس/استیکر/ویدیو/صدا/منشن،
ضداسپم، خوش‌آمدگویی، پذیرش خودکار عضویت)، بن/آنبن، سکوت/آنسکوت، افزودن/حذف ادمین،
وارن/آنوارن، پاکسازی، قوانین گروه.
سرگرمی: تاس (تا ۵۰ تایی با ایموجی واقعی تاس)، شیر یا خط، کوییز (۳۵ سوال)، جرأت یا
حقیقت (۳۴ مورد هرکدوم)، فال، فونت شیک‌کننده متن.
پروفایل و آمار: بیو، لقب، اصالت (ثبت/حذف)، تاریخ شمسی/میلادی، آمار کاربر (پیام، رتبه،
موجودی، لقب/اصالت/بیو)، آمار گروه، تگ اعضا.
اقتصاد گروه: موجودی، افزایش/کسر موجودی توسط ادمین با ریپلای.
ماشین‌حساب: هم با دستور «حساب»، هم به‌صورت خودکار (فقط عبارت ریاضی خالص بفرستی کافیه).
پنل مدیریت کلی (owner): کاملاً دکمه‌ای — کانال‌های اجباری، ارسال همگانی گروه‌ها/پی‌وی،
ادمین‌های پنل، آمار زنده.

## ساختار پروژه
```
rubika-group-bot/
├── bot.py                     # فایل اصلی و روتر پیام‌ها
├── config.py                  # توکن، آیدی مالک
├── database.py                 # لایه SQLite
├── utils.py                    # توابع کمکی + تشخیص نوع پیام
├── force_join.py               # عضویت اجباری با check_join
└── handlers/
    ├── moderation.py           # ضداسپم/فلاد/لینک/فوروارد/گیف/عکس/وارن
    ├── games.py                 # تاس، کوییز متنی، جرأت یا حقیقت
    ├── calculator.py            # ماشین‌حساب امن
    ├── group_admin_actions.py   # فعال‌سازی، تنظیمات، بن/سکوت نرم، ادمین
    ├── admin_panel.py           # پنل کلی ربات (owner)، و start/help/panel
```

## نصب و اجرا

### روی کامپیوتر/سرور (ترمینال معمولی)
```bash
pip install rubka
export BOT_TOKEN="توکن ربات شما"
python bot.py
```

### روی Pydroid 3
تو Pydroid دستور `export` معمولاً همون‌طور که انتظار دارید کار نمی‌کنه (چون هر بار
اجرا با دکمه Run، یک پروسه‌ی جدید بدون اون متغیر محیطی شروع می‌شه). **به‌جاش مستقیم
توی `config.py` این خط رو ویرایش کنید:**
```python
BOT_TOKEN = os.getenv("BOT_TOKEN", "توکن_واقعی_ربات_شما_اینجا")
```
یعنی به‌جای `"PASTE_YOUR_BOT_TOKEN_HERE"` توکن واقعی رو بذارید. اگه این کارو نکنید،
ربات با توکن نامعتبر بالا میاد و ظاهراً «در حال اجراست» ولی به هیچ پیامی جواب نمی‌ده -
یه لاگ هشدار قرمز هم موقع اجرا می‌بینید که همین موضوع رو گوشزد می‌کنه.

بعد از نصب پکیج `rubka` از تب Pip داخل Pydroid، فایل `bot.py` رو با دکمه Run اجرا
کنید و **تب Console** رو باز نگه دارید - همون‌جا لاگ هر پیامی که به ربات می‌رسه رو
می‌بینید (خط‌هایی که با «📩 پیام جدید» شروع می‌شن). اگه بعد از تایپ کردن `start` یا
`شروع` چیزی اونجا ظاهر نشد، یعنی اصلاً پیام به ربات نمی‌رسه (احتمالاً مشکل توکن یا
اتصال اینترنت گوشیه، نه مشکل کد). اگه پیام ظاهر شد ولی جواب نیومد، همون خط لاگ رو
برام بفرستید تا دقیق مشکل رو پیدا کنم.

## راه‌اندازی
1. توکن ربات رو از داخل خود روبیکا (بخش ساخت ربات) بگیرید و در `config.py` یا متغیر
   محیطی `BOT_TOKEN` قرار بدید.
2. ربات رو در پی‌وی باز کنید و دستور `whoami` رو بفرستید تا `chat_id` خودتون رو ببینید.
3. اون `chat_id` رو داخل `config.py` در لیست `OWNER_IDS` قرار بدید.
4. ربات رو به گروه اضافه کنید و داخل گروه بنویسید: `فعالسازی`
5. برای تنظیمات: `تنظیمات`

## پنل مدیریت کلی (owner)
در پی‌وی ربات دستور `panel` رو بفرستید. از اونجا:
- کانال‌های عضویت اجباری: `کانالها`، `addchannel <guid> <عنوان>`، `delchannel <guid>`
- ارسال همگانی: `broadcastgroups <متن>`، `broadcastpv <متن>`
- ادمین‌های پنل: `ادمینها`، `addbotadmin <chat_id>`، `delbotadmin <chat_id>`
- آمار: `آمار`

## راهنمای کامل دستورات
داخل خود ربات با نوشتن `راهنما` قابل مشاهده است.

## نکته درباره تست
چون این محیط به اینترنت دسترسی نداره، این کد از نظر syntax پایتون چک شده ولی به
API واقعی روبیکا وصل نشده و تست زنده نگرفته. لطفاً اول رو یه گروه تستی امتحانش کنید؛
اگه پیام خطایی از سمت کتابخونه `rubka` دیدید (مثلاً اسم پارامتر فرق داشت)، بگید
دقیق پیامش چیه تا بلافاصله اصلاحش کنم.
